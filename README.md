# 🧱 Brick Breaker Game

A fully functional Brick Breaker game built in **Java** using **Swing & AWT**, developed as a 2nd Semester OOP course project.

> **Course:** Object Oriented Programming — Sukkur IBA University (2024)  
> **Team:** Sohail Akhtar & Hamza Butt | BSCS-II Section D

---

## 🎮 Gameplay

Control a paddle to bounce a ball and break all the bricks. Clear all bricks to advance to the next level — miss the ball and it's Game Over!

**Controls:**
| Key | Action |
|-----|--------|
| `←` `→` Arrow Keys | Move paddle left / right |
| `Enter` | Start / Restart / Next Level |

---

## ✨ Features

- 🏓 Smooth paddle & ball physics with collision detection
- 🧱 Multiple levels with increasing brick count & ball speed
- 🎵 Looping background music during gameplay
- 🏆 Real-time score tracking
- 🖼️ Custom pixel-art background
- 💀 Game Over & Level Complete screens

---

## 🛠️ Tech Stack

- **Language:** Java
- **GUI:** Java Swing & AWT
- **Audio:** Java Sound API (`javax.sound`)
- **IDE:** IntelliJ IDEA

## 📁 Project Structure

```
BrickBreakerGame/
├── Main.java        # Entry point — sets up JFrame
├── GamePlay.java    # Core game logic, rendering, input handling
├── Bricks.java      # Brick grid generation & drawing
├── Music.java       # Background music handler
├── BG.jpg           # Background image
└── BeepBox-Song.wav # Background music file
```

## 🚀 Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/SohailAkhtarChanna/BrickBreakerGame.iml.git
   ```
2. Open in **IntelliJ IDEA**
3. Make sure `BG.jpg` and `BeepBox-Song.wav` are in the source root
4. Run `Main.java`
